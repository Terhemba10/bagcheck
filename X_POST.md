## Thread

1/ Did the founders keep their promises, and can you still get out?

Covex is an AI agent built on the @CoinMarketCap API for the #BuildwithCMC hackathon (AI Agents and Automation track).

Live, no sign-up: covex-ai.vercel.app 🎥

2/ Check a coin and you can watch the agent work: every step is a real CMC API call (quotes, DEX security scan, liquidity pools, official links), shown with its endpoint. Scores are computed in code. The AI only explains; it never invents a number.

3/ The Promise check reads a project's own roadmap and lists each dated promise with its status and a word-for-word quote linked to the source. Covex shows what was promised and when. You judge.

4/ Watching a coin needs no account. Covex re-checks it on a schedule and alerts you on Telegram when a warning sign appears. If it went wrong, the rescue plan shows where it still trades, official links only, and it blocks seed phrases.

5/ It also works inside AI assistants: one command adds the Covex MCP server.

Code (MIT): github.com/Terhemba10/covex

Not financial advice. Covex explains data. It never tells you to buy or sell. #BuildwithCMC
